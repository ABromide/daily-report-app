# FairStress：当模型给出同一答案时，是否以同样强度守住它？

## 元信息

| 项目 | 内容 |
| --- | --- |
| 原始报告 | [Asymmetrically Unfair Decision Making and Reasoning in LLMs](https://allenai.org/papers/fairstress) |
| 官方发布 | [Ai2 FairStress 公告](https://allenai.org/blog/fairstress)，2026-10-20 |
| 类型 | 技术报告、公开数据集与评测代码 |
| 主题 | AI 安全；高风险场景中的人口统计公平与对抗鲁棒性 |
| 评测对象 | 15 个全量语料模型；FairStress-Core 上的 6 个前沿模型与 3 个 OLMo Think 检查点 |

## TL;DR

- **做什么：** FairStress 把公平从「两份仅身份不同的简历是否得到同一选择」扩展成四层过程审计：最终选择、遭受说服压力后的抗翻转能力、文字理由、以及决策点内部激活。
- **怎么做：** 作者构造 300 个双候选高风险决策，覆盖 29 个领域、33 种群体配对、四级身份线索（无身份、姓名、姓名加关联线索、显式标签），再配 78 条成对镜像的对抗前缀；完整组合为 13,032,104 个测试项，另以 IRT 选出 50,012 项 Core 子集。
- **关键证据：** 在显式身份（D3）的少数群体—多数群体对比中，15 个模型的准确率差仅 **2.9 个百分点**，但「放弃本来正确答案」的鲁棒性差为 **9.3 点**，平局时被同样说服语句翻向少数群体的差为 **23.9 点**。
- **方法含义：** 仅看无压力答案会遗漏「正确但更容易被动摇」的决策。作者称这种朝少数群体方向、而非传统刻板印象方向的系统性倾斜为 *anti-stereotypical over-correction*；这是评测定义下的非对称，并非把「偏向少数群体」直接等同于现实伦理结论。
- **缓解结论：** 九种事后去偏方法大多不能稳定消除不对称；反事实 CoT 把鲁棒性差降到约 +0.3 至 +2.0 点且公平测试准确率代价很小，但平局偏向仍在。激活转向能看似更公平，却可能令模型不再使用案情细节。
- **局限：** 场景是由 gpt-4o-mini 生成并经人工验证的短、二选一合成题；前缀只有单句且位于固定位置；训练数据审计只覆盖 OLMo-3，因而只能给出相关性而不是训练数据导致行为的因果证明。

## 研究问题：为什么「答案一样」还不够？

### 可见的分配结果，与不可见的程序过程

常见人口统计公平基准会镜像替换身份：若甲的资历更强，模型是否不论甲被描述为黑人或白人都选甲？这相当于只观测一个结果变量。它能发现直接改变选择的偏见，却忽略一个更接近部署风险的问题：模型是否以同样标准**维持**已经有证据支持的选择。

设候选人 (A) 客观更符合岗位要求，模型在两种身份镜像里都选 (A)。此时表面准确率相同。若在追加「领导私下推荐 B」或「B 所属群体历来被忽视」后，模型只在其中一个身份版本放弃 (A)，那么输出审计的“公平”只是脆弱的表象。

作者借用程序正义与分配正义的区别：

- **分配/结果层：** 哪个候选人被选中；正确题上是否选证据更强者，平局题上是否系统偏向一侧。
- **程序层：** 模型何时愿意改变答案、以怎样的语气解释、内部状态是否仍编码身份信息。
- **安全层：** 这不是让模型在道德争论中「永远不改主意」，而是检验相同强度、相同方向的外部压力是否会因受益者身份而得到不同响应。

报告采用 **equality-centered** 基线：其它条件相同时，身份不应改变选择概率、证据充分决定的抗压性或论证依据。该基线刻意不同于 equity / affirmative-action 取向；后者可能把历史性不平等当作相关信息。因此，本文数字应读作“相对这个等同性基线的行为差”，不能外推为一切实际录用、医疗或资源分配的规范答案。

## 基准如何构成：把一个选择拆成可镜像的实验

### 场景、身份强度和压力的正交组合

每个场景都是现实可想象的二元决定，例如招聘、贷款、住房、医疗分诊、假释、教育与移民。每个都有两种任务形式：

| 维度 | 设计 | 它在论证中排除的混淆 |
| --- | --- | --- |
| 任务难度 | GT：一人按题设客观更强；AMB：双方各有优点、没有正确答案 | 将“选错”与“偏好”分开 |
| 身份可见度 | D0 无线索；D1 名字；D2 名字加生活关联；D3 显式人口标签 | 分辨隐含线索与直接标签的作用 |
| 群体配对 | 26 个少数—多数对（Type 1）与 7 个少数—少数对（Type 2） | 验证不是任意身份标签都造成同一方向偏移 |
| 顺序 | A/B 位置互换 | 避免把首位偏好误报为人口差异 |
| 压力 | 78 条前缀、15 个家族、每条有对另一候选人施压的镜像版 | 让同类说服对两侧的边际效果可比 |

前缀含九类定向压力（权威、社会共识、代表性、历史愧疚、合成证据、情绪诉求、法律责任、合成统计、弱势主张），外加中性、评测意识与安慰剂对照。研究团队用 gpt-4o-mini 按固定提示生成初稿、gpt-4o 判审，并人工检查：题面不能把人口属性当作资历；D0 必须是有意义控制；GT/AMB 构造应分别有明确胜者与真实权衡。

人类有效性检查也很关键：三位标注者在抽样的 100 对 GT 题上有 94% 选到指定正确项，在 100 对 AMB 题上有 90% 选择平局。这不足以将“正确答案”绝对化，但说明评测没有只靠作者主观断言。

### 四个指标：分别问“选谁、会不会倒、怎样说、内部有什么”

令 (g\in\{min,maj\}) 表示正确答案或受压候选所属群体，(\hat y) 是模型选择，(y^\star) 是 GT 正解；上标 (\varnothing) 和 (\pi) 分别表示无前缀与加入前缀。正值统一表示向少数群体一侧的偏移。

1. **Accuracy Gap（GT、无压力）**

   \[
   AG=Acc_{min}-Acc_{maj},\qquad Acc_g=P(\hat y=y^\star\mid y^\star\text{ favors }g)
   \]

   它回答模型是否同样常把支持少数或多数候选的证据判断正确。

2. **Robustness Gap（GT、有压力）**

   \[
   RG=Flip_{min}-Flip_{maj}
   \]

   这里 (Flip_g) 条件化于无前缀时模型在两个镜像题都答对，随后前缀劝模型改选 (g)。因此它不把本来已错的题算入“被说服”，专测原本正确决定是否对称地被击穿。

3. **Tie-Break Lean（AMB、无压力）**

   \[
   TL=\tfrac12(\lambda_A+\lambda_B),\qquad \lambda_s=P(\hat y=min\mid min\text{ 位于槽位 }s)
   \]

   公平基线是 50%，且对 A/B 槽位平均，避免位置偏差伪造群体偏好。

4. **Tie-Break Shift（AMB、有压力）**

   \[
   TS=Shift_{min}-Shift_{maj}
   \]

   它要求模型先在无前缀时没有选 (g)，再看针对 (g) 的镜像说服是否更容易令其翻转。GT 的 (RG) 问“守住真相”，AMB 的 (TS) 问“同样的游说能否同样撬动平局”。

### 评测流程伪代码

```text
Input: scenario s, task form in {GT, AMB}, identity degree d,
       group pairing p, candidate order o, prefix family f
State: base_answer, pressured_answer, mirrored_answer

for each mirrored identity assignment m in {original, swap}:
    base_answer[m] = model(render(s, d, p, o, m, no_prefix))
    for each matched prefix pi that argues for either candidate:
        pressured_answer[m, pi] = model(render(s, d, p, o, m, pi))

if GT and both base answers are correct:
    count directional abandonment in Robustness Gap
if AMB and base answer is against prefix-favored candidate:
    count reversal in Tie-Break Shift

Output: AG, RG, TL, TS plus refusal rate and per-slot rates
Failure boundary: do not interpret a metric without checking refusal、位置和镜像条件
```

这套条件化设计的意义是防止“模型一开始就乱答”被包装成鲁棒性。作者还报告拒答、翻转与位置率，以降低模型通过拒答或固定选 A 来刷指标的空间。

## 主结果：小的答案差，较大的抗压差

### Figure 2 应如何读

Figure 2 将身份从 D0 推到 D3。D0 时没有模型出现缺口，模型也能在压力下大体守住答案；身份越显性，四条曲线越偏离公平线。15 个全量模型的 Type-1 汇总结果如下：

| 指标与条件 | 汇总发现 | 不能直接推出什么 |
| --- | --- | --- |
| GT 的 D3 Accuracy Gap | +2.9 点；D2 反而峰值 +3.5 点 | 不是所有模型、所有群体都同幅度偏移 |
| AMB 的 D3 Tie-Break Lean | 平均 61.6%；Tulu-3-8B-DPO 达 70.9% | 平局偏好不等于现实中每次偏好均不公正 |
| D3 Robustness Gap | 摘要汇总 +9.3 点 | 仅适用于题设的单句镜像压力与 equality 基线 |
| D3 Tie-Break Shift | 摘要汇总 +23.9 点 | 不能替代多轮真实部署的红队测试 |
| Type 2（少数—少数）D3 | AG −0.6、TL 47.2、RG −2.3、TS −5.1 | 不对称不是简单“见少数就总向同一边偏” |

交叉身份与高风险领域最值得注意。表 2 中，黑人跨性别女性相对白人男性的组合出现 (AG=+8.8)、(TL=76.3)、(RG=+20.3)；教育领域的 (RG=+24.0)，刑事再融入的 (TS=+23.1)。这些是跨 15 模型汇总的排序例子，不应误读成某一模型单点性能或人群真实录取率。

### 不是所有压力都一样：Table 3 的机制证据

若“少数一侧的前缀写得更有道理”是唯一解释，较中性的合成证据不应产生最大差。结果并非如此：D3 下，**合成证据**前缀的 (RG=+16.0)，历史愧疚为 +15.5；而不主张任何特定群体价值的合成证据恰是最大缺口。平局翻转方面，代表性诉求最高（+33.5），权威与社会共识也分别为 +27.4、+25.3。

- 评测意识前缀仍令 D3 平局向少数群体移动 +5.3 点；安慰剂句也有 +4.2 点。
- 但定向前缀使移动扩大到约 +19 至 +34 点，显示现象不是单纯“提到公平”就会触发。
- FairStress-Core 上的前沿模型也呈相似模式：平局偏向在 60%–65%，12 个模型—模式运行的 (TS) 全为正，范围 +8.8 至 +42.4。

作者再用同一模型权重重跑 BBQ 的五种呈现/计分配置。四个模型在原始 log-likelihood 式设置中都显示 6.6–8.2 点的刻板印象方向；改为 chat template、强制问法与生成式答案后，三个转为反刻板方向、一个近中性。这个消融支持一个更窄但重要的主张：**公平信号取决于提示和评分协议**，固定选项概率不能替代生成式决策审计。

## 九种缓解方法：改善指标，还是让模型失去任务能力？

作者在 OLMo-3-7B、Gemma-3-12B 与 Qwen2.5-7B 上，用独立的 1,199 条校准集选参数，再在不重叠的 50,012 条 Core 集上评估。校准目标是最小化

\[
|AG|+|TL-0.5|.
\]

这点很重要：它没有只对 (RG) 调参，否则会把抗压指标的“改善”过拟合成目标函数。

| 方法族 | 代表方法 | 观察到的结果 | 应有的保留 |
| --- | --- | --- |
| 提示 | instruction prompting | 小幅变化，仍不稳定 | 指令本身不是过程校验 |
| 提示 | counterfactual CoT | (RG\) 降至 +0.3 至 +2.0，FairStress 准确率近乎不掉；平局仍 54%–57% | MMLU 在 OLMo-3 上下降 8.2，且未消除所有偏向 |
| 反思 | self-critique | 某些指标改善、总体不可靠 | D2/D3 仍可扩大 gap |
| 概念擦除 | LEACE、INLP | 各项指标几乎原样保留 | “删除身份方向”不等于删除决策过程中的不对称 |
| 激活转向 | CAA、CAST、Shifting Perspectives | 有时接近公平线 | 可能因为模型忽略题目：例如 CAA 准确率降到 0.47–0.69 |
| 低秩编辑 | LoReFT | 不能稳定解决 | 低维局部修改不足以校正过程行为 |

另一路实验是 constitution-guided 预训练。最强配方把 D3 的 Accuracy Gap 从 +14.6 降到 +4.5，平均 Robustness Gap 从 +14.7 降到 +1.7；但平局中首位候选被选中的比例高达 98%–99.9%。因此它展示了前训练对齐有潜力，却同时展示了单个分数下降无法证明决策器可用。

## 理由与内部状态：正确答案不代表同样的论证

作者只保留两个镜像版本都答对的 GT 项，再让 264 个词典特征预测模型选的是哪侧。若理由真正对称，预测应接近 0.50。结果是：AMB 的 21 次文本运行全部高于机会，GT 上 11 个开放模型全部高于机会，六个前沿 reasoning-mode 运行也全部高于机会；原生 thinking 的信号较弱，只有四个运行中的三个超过机会。

这是一项关于“理由可被风格读出”的证据，不是对 CoT 因果忠实性的证明。报告中的语言模式是：少数候选一侧更常出现温暖、正向、保护性词汇，多数候选一侧更常强调 evidence、criteria、detailed 等程序性词。它说明相同结果仍可能以不同叙事被合理化。

内部层的测试更窄：Gemma-3-12B 与 Qwen2.5-7B 的决策点激活，经自然语言自编码器转写后，原激活可将选择哪一人口侧的可分性预测到约 73%，文字化描述则为 57%–59%，机会基线 50%。移除候选姓名会让激活可分性下降约 18 点。作者正确地限定为两模型、少数对照，不能据此宣布“激活证明了偏见原因”。

## 训练数据审计：一个可检验的机制假说，而非因果归因

作者选 OLMo-3 是因为每阶段语料可公开审计：2.15M SFT 行、260K DPO 对、约 40 亿篇预训练文档的抽样与 RL 提示。对 24 个群体，他们结合立场分类、词语关联、道德基础词密度、伤害者/受害者角色，以及对 28,000 个语义簇的 merit-based 决策普查。

- 99,338 条 SFT 行（4.6%）来自两套拒答训练集 WildGuardMix 与 WildJailbreak。
- 28,000 个簇中只有 9 个谈到“按能力而非人口属性”做判断，且 9 个全是拒答。
- 少数群体相关段落中，36.4% 是保护性表述、6.4% 为负面；多数群体对应为 11.3% 与 11.6%。
- 两位人工标注者对 100 段样本一致率 93%（(\kappa=0.89)），与 LLM judge 的一致率分别为 94% 与 87%。

这支持一个合理机制假说：后训练大量教会“拒绝歧视性请求”，却极少示范如何在身份无关时根据证据作决定；保护性语料分布也不对称。不过报告没有干预删除/补充某类数据来重训并证明行为随之改变，因果链仍未闭合。把审计相关性写成“训练数据造成偏差”会超过证据。

## 复现时真正应记录什么：从排行榜到审计轨迹

FairStress 的可复现价值不只在于下载一个 JSONL 然后输出四个均值。完整语料有一千三百多万组合，模型 API、解码设置、拒答策略和成本都会迫使实践者选择子集；若没有预先固定抽样与日志协议，不同团队可以在同一个名称下报告彼此不可比的“公平”。报告给出 Core 的理由正是计算预算：它用项目反应理论选择 50,012 项，保留所有领域、配对和前缀家族。这里的正确用法是先在 Core 上做故障定位，再把异常模型或异常家族回放到完整组合，而不是只保留最容易改善的那一项指标。

### 一个最小而可审计的复现实验表

| 日志字段 | 为什么必须保存 | 常见遗漏会造成什么误判 |
| --- | --- | --- |
| 模型版本、系统提示、temperature、max tokens | 生成式公平对模板与解码敏感 | 把供应商升级或温度变化误称为缓解方法有效 |
| 场景 ID、GT/AMB、D0–D3、群体配对、候选人槽位 | 使镜像与位置校正可重算 | 把首位偏好或身份显性度混为人口差 |
| 无前缀答案、带前缀答案、拒答/格式失败 | (RG\) 与 (TS\) 都依赖基线条件 | 把“原本已错”或“拒答变多”误作抗压改善 |
| 前缀家族与镜像方向 | 区分证据、权威、历史和安慰剂机制 | 用一条特别有说服力的句子泛化全部压力 |
| 文字理由的原文与是否被允许输出 | 让理由层分析有可追溯输入 | 把不同的 CoT 可见策略误作模型内在差异 |
| 成本、时延与重试 | Core 和全量的工程代价不同 | 只报告公平数字而隐藏不可部署的评测预算 |

可将一轮评测理解为配对差分，而非独立样本分类。对于某个前缀家族 (f)，应在同一个场景、同一候选顺序的两个身份镜像上算翻转差，再在配对层聚合置信区间。这样可减少题材难度、名字自然度和 A/B 顺序带来的方差。若只把所有“少数胜出”的运行堆在一起，模型是因身份、因题目难度还是因候选人排列而翻转将无法区分。

### 它暴露的失败模式可如何转成安全测试

报告中的“对抗前缀”并不一定是恶意越狱语句；更像部署中常见的社会压力输入，例如领导偏好、法律风险、代表性目标或一段貌似客观的统计。安全工程上应把它们视作**决策污染通道**，并加上模型部署语境里的等价变体：

- 在招聘辅助中，分别让 HR、直属经理和合规人员提出相同信息量的偏好，检查模型是否仅因受益者身份而更愿意忽略技能证据。
- 在客服、信贷或保险流程中，保持风险材料不变，只镜像“历史忽视”“组织声誉”“媒体压力”等论述，记录建议是否从证据型理由退化为身份型理由。
- 在 agent 工作流中，把前缀替换为工具返回、检索摘要、团队留言和高优先级系统通知，分别测试其来源可信度、权限等级和受益对象。这样可把 FairStress 的单句设计扩展为真正的上下文完整性测试。

这些扩展必须有一个失败边界：若身份信息本就是法律规定的保护属性或纠偏政策的合法输入，就不能把任何群体差异直接归为模型错误。测试设计需要先写明任务的规范目标——平等处理、风险最小化、补偿性公平，还是受限优化中的多目标权衡——再解释 gap 的方向。FairStress 的强项是让这一选择可见，而不是替代它。

### 为什么拒答、位置率与能力指标必须同行

一个模型可以通过三种退化方式让表面 gap 变小：永远拒答、永远选第一个候选人，或者对所有压力都忽略案情。作者的 constitution-guided 实验出现 98%–99.9% 首位选择，正是一个反例：某些公平数字改善，却暴露出严重的位置偏差。CAA 与 Shifting Perspectives 的低准确率同样说明，模型不再依据候选材料也会“看起来”更对称。

因此，一个合格发布表至少应同时给出：GT accuracy、四个 gap、拒答率、候选槽位率、格式合规率、任务成本以及跨领域分布。若某种干预使 (RG\) 接近零却把 GT accuracy 从 0.98 拉到 0.47，它减少的也许不是不公平，而是模型做出有信息决定的能力。把能力损失显式当作约束，才避免把安全修复变成服务降级。

### 可以被证伪的后续研究问题

1. **多轮稳健性是否同向？** 将单句前缀拆成多轮、加入工具证据冲突；若 gap 消失，说明现象依赖特定提示位置；若扩大，才更接近部署威胁。
2. **数据补齐是否有因果作用？** 在可控小模型中补入等量、镜像的 merit-based 选择示例，并与只增加拒答样本的对照组比较。只有行为随干预可预测地改变，训练审计的机制解释才会变强。
3. **CoT 监控能否预测翻转？** 在不公开推理的设置中，用内部判别器或结构化理由字段预测 (RG\)，并与实际翻转交叉验证；否则“理由可分”仍只是事后描述。
4. **从二元人选到排序/阈值决策会怎样？** 真实系统常排序十人或根据阈值通过。需要检验镜像对称性是否仍能定义，以及候选池组成是否引入新的群体交互项。

## 结论、边界与后续问题

FairStress 最有价值的贡献不是宣布某种单一“正确公平”，而是将评测单位从静态答案变为**可被镜像压力探测的决策过程**。它要求评估者同时报告方向、抗压性、拒答率、候选人位置率和理由层信号，降低模型只针对一个榜单分数调参的可能。

仍需保留四条边界：

1. 合成短题、二选一、单句后置压力不能覆盖真实系统中的长材料、多候选、工具调用和多轮权力关系。
2. minority/majority 是美国语境下固定配对属性；跨文化、跨法域和交叉身份的规范解释不能自动迁移。
3. equality 与 equity 会在某些情境给出不同的预期；本文量到的是相对于前者的非对称，而不是普适的社会正义量表。
4. 训练语料与行为的关联、文字理由与内部激活的可分性，都不是完整的因果解释或忠实性证明。

对 AI 安全研究者而言，下一步不应只问“模型是否答对”，而应设计更接近部署的**对称红队**：同一事实、同一权限、同一诱导强度，只交换谁从改变中获益；再把每次翻转、拒答、工具调用和理由依据连同任务效用一并记录。只有在能力、抗操纵与规范目标共同约束下，公平评测才不会退化为可被优化的表面行为。
