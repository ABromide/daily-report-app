# 数千个 Agent 如何把全脑 CRISPR 图谱变成可检验的研究线索

> **原始发布：** OpenAI，2026-10-21；**类别：** 大模型 Agent；**论文：** Sun 等，bioRxiv 预印本（2026-10-16，尚未同行评议）；**代码：** `jinlabneurogenomics/distributed_agent`。

## TL;DR

- 这项工作不是让一个更强的模型“读懂生物学”，而是把全脑 CRISPR Perturb-seq 图谱按扰动拆给约两千个 GPT-Rosalind Agent：每个 Agent 读取一个基因扰动的细胞类型表达反应、检索文献、提出解释，再聚合为可浏览的 reasoning atlas。
- 官方披露的端到端运行处理了数百万个小鼠脑细胞、耗时 **32 分钟**；第三方可核查的配套材料把具体规模列为 **1,946 个 Agent、约 772 万细胞、近 2,000 个疾病相关基因、19,070 个 mRNA 与 8,588 个 sgRNA**。两组数字的口径不同，本文不把它们混为同一测量。
- 在固定模型与资源的最大工作负载对照中，单 Agent 只引用 **11** 篇文献，分布式系统引用 **700+** 篇；盲评专家在成对比较里 **75%** 选择分布式报告。这首先证明了覆盖面与报告偏好，不等于已证明所有提出的机制为真。
- 代表性线索包括：小脑中 `Tsc2` 扰动而非 `Tsc1` 扰动关联数十个神经传递相关基因的变化；以及 `Dctn1` 扰动后胆固醇合成相关基因上调、可能涉及神经元内胆固醇转运的假说。它们是下一轮湿实验的问题，不是疾病治疗结论。
- 可复现性是此项目的强项：仓库给出 Agent runtime、语料工具、保存的 run、图表 notebook 和部分原始结构化输入；弱点也透明存在：预印本未审稿、基础图谱和合作方高度相关、Agent 会在缺乏可用邻居或强耗竭时漏报或过报。

## 它试图解决的到底是什么？

现代扰动图谱把“能测到什么”推得远快于“人能解释什么”。研究者可以逐一敲除或扰动大量基因，记录不同细胞类型的转录响应；真正困难的不是得到一张差异表达表，而是回答：这个响应是否可信、和已知通路哪里相连、是否值得花实验资源追下去？

传统工作流通常是一个研究者挑最强信号、查有限的文献、再设计验证。这样做深度高，却天然会遗漏弱而不寻常的模式。OpenAI、PerturbAI 与 Scripps 的问题因此可写成：

\[
\text{给定 }D=\{(g,c,\Delta x)\},\quad \text{如何在固定推理预算 }B\text{ 内最大化可追溯的候选解释？}
\]

其中 `g` 是被扰动基因，`c` 是细胞群，`Δx` 是表达变化。这里的“最大化”不是只最大化回答数量，而是同时要求每个回答能回指到观测、文献与待验证的机制。因此产物不是一段总摘要，而是一张把 **扰动—细胞效应—引用—主张—候选机制** 连在一起的 atlas。

## 论证路线：从并行切分到研究问题

作者的核心主张可以拆为四步，而不是一句“Agent 发现新药靶点”的宣传语。

| 环节 | 要做什么 | 产物 | 应如何评价 |
|---|---|---|---|
| Claim | 大型图谱中有大量人类不会逐项阅读的线索 | 需要扩展搜索的动机 | 不等于所有低频信号都有价值 |
| Mechanism | 每个扰动一个独立 Agent，结合表达数据与文献 | 分扰动报告 | 降低单任务上下文竞争，而非提高模型生物学真值 |
| Evidence | 与单 Agent 固定资源对照、盲评和已知生物学回收 | 引用覆盖与专家偏好 | 两项指标都不是湿实验验证 |
| Boundary | 将最有价值的报告转成实验设计 | 可检验假说 | 仍需要独立数据、干预和因果验证 |

以 `Dctn1` 为例，系统不是声称“DCTN1 导致神经退行”。它先观察到扰动后胆固醇合成基因的表达升高；再把这一模式与关于细胞内胆固醇运输的文献接起来；最后提出可被证伪的问题：扰动是否改变胆固醇在神经元内的分布，恢复运输能否保护细胞？这种从观测到问题的收束，才是 reasoning atlas 的合适单位。

## 分布式 biological reasoning 怎样运行？

一个 Agent 的最小任务并不神秘，但有明确的输入、状态与失败边界。

```text
Input: perturbation g, cell-type-resolved Δx, literature corpus L
State: observed effects E, retrieved sources R, claims C, uncertainty U
for each relevant cell group c:
    summarize E[g, c] and check signal / coverage
    retrieve literature candidates from L
    separate observed fact from proposed explanation
    append citation-backed claim to C; append gaps to U
Output: report(g) = {E, R, C, U, follow-up experiments}

Failure boundary:
    if empirical comparators are absent, do not turn a null search into a null effect;
    if depleted cells are selectively missing, flag that observed Δx can understate impact.
```

项目公开仓库把这条流水线实现为 runtime、语料工具和 notebook：本地完整复现需要 Git LFS 数据，先执行一次数据准备，再运行主与补充图表 notebook；托管 MCP 端点只读且不携带原始数据，因而不能重算依赖原图谱的统计量。这个边界很重要：能够问到已发布 Finding，不等于能够独立重做每一项差异表达。

下面的 Mermaid 图强调了“并行报告”与“科学确认”之间有一道不可跳过的闸门：

```mermaid
flowchart LR
  A[全脑 CRISPR 图谱] --> B[按基因扰动分片]
  B --> C[并行 Agent: 表达 + 文献]
  C --> D[带引用的扰动报告]
  D --> E[reasoning atlas]
  E --> F[专家筛选与实验设计]
  F --> G[独立湿实验/复制]
  G --> H[可接受或推翻机制]
```

## 为什么并行会改变结果？

官方对照刻意固定了模型和资源：问题不是“多 Agent 多花钱所以更好”，而是同一预算在一个长上下文代理与许多窄上下文代理之间怎样分配。最大负载时，单 Agent 的文献引用从搜索空间中塌缩到 **11** 篇；分布式系统保留 **700+** 篇。这个结果可以用一个简单的覆盖率视角理解：

\[
\mathrm{Coverage}=\frac{|\bigcup_{i=1}^{N}R_i|}{|R^*|},\qquad
\mathrm{Redundancy}=\frac{\sum_i|R_i|-|\bigcup_i R_i|}{\sum_i|R_i|}
\]

`R_i` 是第 `i` 个 Agent 的引用集合，`R*` 是该任务可获得的相关文献集合。更多 Agent 往往提高分子，但也可能提高重复与低质量引用；因此 700 对 11 是**覆盖能力证据**，不是“700 篇都正确”的证据。系统真正需要继续报告的指标应包括引用可访问率、主张被证据直接支持的比例、相互矛盾的报告率与每条可行动线索的成本。

盲评中，专家 75% 的时间偏好分布式报告，说明它们在新颖性、后果性或后续价值的主观评估上更有说服力。可是盲评偏好仍有三层不能推出：第一，专家是否看到了完整原始数据与提示；第二，比较样本数、专家构成和置信区间在公告中未完整展开；第三，被偏好的报告可能更全面，也可能更流畅。它不能替代一个预注册的湿实验成功率。

## 两个应当怎样读的案例

### `Tsc1` 与 `Tsc2`：不是“同一路径必然同一转录后果”

两者都参与 mTOR 调控。公告称，在若干神经元群它们的扰动结果相近；但在小脑，`Tsc2` 扰动改变了数十个与神经通信有关基因的活性，`Tsc1` 则几乎没有变化。该差异的价值在于把一个泛泛的通路叙事压缩成细胞类型特异的比较实验：在相同时间窗、同一小脑细胞群中，哪一个节点造成何种下游改变？

配套代码材料同时给出一个必要的反面提醒：保存的案例中 `Tsc1` 真实差异表达基因数为 **321**，分布式 Agent 的预测为 **80**，约相差 4.0 倍。即使方向或主题有启发性，数量级也会错。因此 atlas 应用于优先级排序时，应显示观测值、预测值和误差，而非只展示漂亮标题。

### `Dctn1` 与胆固醇：一个好假说不等于一个已发现的疗法

`DCTN1` 突变与 Perry 综合征相关。图谱里 `Dctn1` 扰动后，胆固醇合成有关基因上调；Agent 将其与“运输受阻时细胞可能提高合成”的文献解释相连。这里可检验的预测是：

1. 变化是否在特定神经元类型、时间点与剂量下可复现；
2. 是否真的存在细胞内胆固醇分布改变，而不仅是合成转录程序；
3. 调整运输是否改变细胞健康或疾病相关表型。

仓库的专家比较表中，`Dctn1` 的人类与分布式标题都指向神经元 sterol-biosynthesis 程序，属于“match”而非独立因果确认。这说明 Agent 与人工表述发生了有用的一致，而不是已经完成机制实证。

## 失败、消融和数据选择偏差

预印本及其公开输入并未把失败藏起来，这比单报成功案例更值得看。

| 失败模式 | 公开案例 | 这意味着什么 |
|---|---|---|
| 漏报 | `Naa20` 缺乏合格 STRING 邻居，预测 0 个 DEG，实际观察到 1,327 个 | 相似性检索没有邻居时，不能把“没有证据”变成“没有效应” |
| 过报 | `Pomp` 实际 4、预测 600；`Thoc2` 实际 0、预测 303；`Pafah1b1` 实际 0、预测 40 | 文献上合理的强效应可因采样、细胞损失或测量窗口而在图谱中不可见 |
| 选择偏差 | 强耗竭命中更易产生预测误差 | 被编辑后消失或未被充分采样的细胞会让观测效应偏小 |
| 访问边界 | 托管 MCP 没有原始数据 | 浏览结论者无法据此复算统计或确认输入处理 |

这张失败表改变了我们对 Agent 的正确用法：它不是用来替换统计检验的裁判，而是用来提出对统计结果最有解释力、同时最应被实验否定的候选。尤其是“预测很强、实测很弱”的条目，应该优先检查耗竭、细胞筛选和时间点，而不是直接给模型贴上幻觉或发现的标签。

## Figure/Table 证据应怎样使用

- **官方规模/速度叙事：** 数百万细胞与 32 分钟说明并行流水线吞吐，不说明每个 Agent 的准确率或单位成本。
- **固定资源引用对照：** 700+ 对 11 是最直接的系统级证据，支持“长任务的检索覆盖会随集中化而退化”的判断；它没有给出精确召回率。
- **盲评偏好：** 75% 是人类评价信号，支持报告实用性；没有直接测量随后湿实验的成功概率。
- **公开 CSV 与 notebook：** `Tsc1` 近失配、`Pomp/Thoc2/Pafah1b1` 过报让失败可以被审计；这比只展示 DCTN1 线索更能约束结论。

## 与相关路线的关系

该工作处在三个传统之间：Perturb-seq/细胞图谱提供可量化观测；文献检索与知识整合提供解释候选；多 Agent 编排把大量窄任务并行化。它不同于只在问答 benchmark 上比较 Agent，也不同于只训练一个端到端的细胞状态预测器。其贡献更准确地说是把“解释图谱”变成可浏览、可审计的中间产物。

不过，公开代码使用 Codex CLI 作为默认运行入口、语料发行与 Git LFS 数据作为复现依赖，意味着复现仍有环境、访问与成本门槛。未来最关键的外部验证不是再做一次同一图谱的漂亮 demo，而是由无关团队在另一种物种、另一类扰动、不同文献库和预先定义的湿实验判据上测试：atlas 排名前列的假说是否比专家基线更常被验证。

## 从工程视角拆解：分片并不自动等于可靠

把一个任务拆成很多 Agent 常被说成“更可扩展”，但这个词至少混合了四种不同能力。第一是**计算并行性**：若每一个扰动报告相互独立，墙钟时间可以从各任务时间之和接近最大单任务时间加聚合开销。第二是**检索并行性**：多个独立检索轨迹更可能接触不同文献。第三是**认知多样性**：不同提示、上下文或随机性可能给出不同解释。第四才是**科学可靠性**：解释能否在新数据和实验中站住。前面三项可以借由增大 `N` 改善，第四项不可以直接外推。

可将一次运行的实际成本表示为：

\[
C_{run}=\sum_{i=1}^{N}(C_{model,i}+C_{retrieve,i})+C_{aggregate}+C_{review},
\]

而可行动价值更接近：

\[
V_{action}=P(\text{假说可复现}\mid \text{evidence})\times U_{experiment}-C_{validation}.
\]

这两个式子提醒一个容易被速度数字遮住的事实：32 分钟只描述 `C_run` 的时间维度，不能估计 `P(可复现)`。如果系统因并行产生一千个看似合理的候选，研究团队仍要承担筛选、试剂、动物模型与失败实验的成本。真正成熟的 atlas 应当把每个候选的证据密度、模型不确定性、相似先例、数据缺口和建议验证方式并排展示，让实验室选择一个期望价值而非语言流畅度最高的报告。

这也是公开 repository 的价值所在。README 明确区分了托管只读语料浏览和本地完整运行：前者可以检查报告里的 Finding、Claim 与支持证据，后者才可获取原始数据并重算统计。这样的产品边界避免了一个危险误解——用户在聊天界面里看见引用，不等于每项统计已经在当前会话被重新计算。对于 Agent 系统，**可追踪的来源**与**可复现的计算**应是两个分别声明的属性。

此外，任务分片本身会造成协调问题。假设两个 Agent 分别看到同一生物通路的不同基因，它们可能引用重叠文献、给出相容但重复的假说；也可能因为术语不同而给出表面冲突的解释。聚合器的责任不是把句子拼成更长摘要，而是建立实体规范化、合并相同证据、标出矛盾、保留每条结论的源报告。若该层只是“多数投票”，就会把高频但缺乏直接支持的叙事放大。文中所谓 reasoning atlas 的研究价值，恰在于它有潜力保存这条从数据到主张的 provenance，而不只是一个结果页面。

## 一个负责任的评测协议应当长什么样？

本文已有的对照回答了“并行系统是否让专家更喜欢报告”；它没有完整回答“系统是否使科学发现更快、更真或更便宜”。若要把后一个问题做成可检验主张，建议把评测分成三层。

### 第一层：证据与推理的静态审计

- 从 atlas 随机抽取主张，独立标注其是**数据描述**、**文献事实**、**推断**还是**实验建议**。系统不应把后两类写成前两类。
- 对每条引用测量可访问率、是否真的支持紧邻的主张、是否存在更直接的反证。这里的准确率比“引用总数”更重要。
- 让不参与系统开发的领域专家在隐藏模型身份的条件下，评估证据充分性、可证伪性、表达清晰度与是否夸大因果。

### 第二层：跨数据集的预测试验

- 在一个图谱上限制 Agent 只能访问训练部分或已发表时间点以前的文献，在真正保留的扰动、细胞类型或后续数据上检查预测。
- 不只公布平均分，还要按稀有细胞、强耗竭、低表达基因和缺乏文献的长尾切片。公开反例表已经暗示这些区间的错误结构不同。
- 基线至少包括：单 Agent、人工文献综述、检索增强但无分片的模型、简单的相似邻居法。否则“多 Agent 有用”会混入检索、模型版本和数据清洗的收益。

### 第三层：湿实验前瞻验证

1. 在系统运行前锁定若干候选和判定标准；
2. 将候选按不确定性与预计价值分层抽样，而非只挑最好讲故事的 DCTN1；
3. 用独立实验室或至少独立数据批次完成验证；
4. 同时报出阳性率、失败原因、每个有效线索的总成本和人为基线的同类数字。

只有第三层才能支撑“发现加速”的强表述。即便最终阳性率并不高，第一、二层也仍然有工程价值：它们能告诉我们模型在哪类数据上过度自信，以及怎样把失败排到实验前。对研究型 Agent 来说，能可靠地说“这里不该相信我”往往比多写十条机制更重要。

## 对 Agent 设计的三个可迁移启示

### 1. 用任务边界而不是角色名称定义 Agent

“文献 Agent”“分析 Agent”这类角色名称太宽。这里更有效的单位是 `一个扰动 × 一组细胞响应 × 一个可查询语料`。边界清楚后，输入可冻结、输出可比较、失败可以归因。其他领域也可借鉴：安全审计可以按依赖路径或权限边界分片，后训练分析可以按数据切片或失败模式分片，但不能把相互依赖的决策假装成独立任务。

### 2. 让不确定性成为输出字段

如果报告只输出“解释”，后续读者会自然把语言自信度当成证据强度。较好的结构应要求每个 Claim 至少携带：观测来源、引用来源、支持类型、相反解释、缺失数据和建议的区分实验。可写为：

\[
\text{Claim record}=\{o,\ r,\ h,\ a,\ u,\ t\},
\]

其中 `o` 为观测，`r` 为引用，`h` 为假说，`a` 为替代解释，`u` 为不确定性，`t` 为下一项检验。这样的字段化不是形式主义；它让聚合器和人类 reviewer 都能拒绝没有观测或没有可证伪路径的漂亮段落。

### 3. 以失败簿而非成功故事校准部署

`Naa20`、`Pomp`、`Thoc2` 和 `Pafah1b1` 这些反例说明，错误并非随机噪声，而与训练邻居、细胞耗竭和测量可见性有关。将其做成 failure ledger，能指导路由：若目标处于高耗竭区，系统应降低机制断言等级并优先建议检查细胞存活；若没有合格文献邻居，应明确报告证据空白而非输出零效应。对任何高风险或高成本的 Agent 工作流，部署阈值都应由这类条件化错误率决定。

最后还要区分“系统找到了过去文献中已经存在的关联”与“系统产生了真正的新知识”。前者并不低价值：它证明一条自动化检索、组织与解释链能把分散证据送到正确的实验问题旁边。后者却必须经过时间上的保留集、独立数据和干预实验。将两者标成不同证据等级，才能避免把可读的综合报告误报为已经确立的科学发现。

## 结论与继续追问

这项研究给 Agent 领域的最强启示不是“把 Agent 数量拉高就会产生发现”，而是可以把**大规模可观测数据**、**可引用的解释过程**和**明确的实验闸门**接成一条可审计管线。其最可信结论是：在这个图谱与该对照设定中，分布式设计扩大了文献覆盖并获得了更高的专家报告偏好。

应当暂缓的结论也同样清楚：DCTN1—胆固醇关系尚不是经验证的疾病机制；TSC1/TSC2 差异尚不是普适规律；32 分钟也不是从数据到新疗法的时间。下一步应报告预注册的验证命中率、引用正确性、计算成本、跨图谱迁移和错误校准。只有当 atlas 经过这些检验，它才会从“有用的科学写作与检索系统”走向可靠的发现基础设施。
